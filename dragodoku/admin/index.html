Mint gift codes

Players redeem codes in Settings → Redeem a gift code, and each code works once. A dragon code holds one exact dragon with its serial number reserved now. An egg code gives an egg that hatches in the app like any other, so its dragon gets the next serial when it hatches.

Air drops and gifts

Send a gift straight into players' apps (app 1.7.0 on), with no code to type. An air drop goes to players picked at random from those who solved a daily puzzle recently; a gift goes to one player you name. They see it, with your message, the next time they open the app (older versions get it once they update). Each one is a gift code minted for that player only, so it also shows under Recent gift codes.

Tamer names

The app already blocks rude words, so this is for anything that slips through. Players can report a name by tapping it on a leaderboard, and a name that three established players (three or more timed dailies) report is hidden automatically. Hiding a name takes it off the leaderboards within about 15 minutes; unhiding it sticks. The player sees that it was hidden, and once they choose a new name (allowed about once a day) they reappear.

App error reports

Uncaught errors sent by the app (1.5.0 on): version, Android version, the error and the top of the stack, grouped by where in the code they happened. No personal data; at most five a day per player; the server deletes them after 30 days. Crashes that close the app, and freezes, are in Play Console → Monitor and improve → Android vitals.

Find a dragon

For support and privacy requests: players can send the species and serial number from their card (for example #AAA-0412: runs of 9,999 per species, AAA first). Deleting registry records never reuses a serial number.
